# C Programming — Structural Programming

Welcome to my **Structural Programming** repository.

This repository documents my learning journey through **C programming** during my first year of undergraduate study. It contains coursework, laboratory exercises, assignments, problem-solving programs, and other practice work completed throughout the course.

## 📌 Repository Overview

The main purpose of this repository is to build a solid foundation in programming by learning how to analyse problems, design solutions, and implement them using C.

Rather than focusing only on programming syntax, the coursework emphasizes developing a structured approach to solving problems and understanding how programs work internally.

## 📚 Course Coverage

The programs and exercises in this repository cover fundamental areas of C programming, including:

* Basic syntax and program structure
* Variables, constants, and data types
* Arithmetic, relational, and logical operators
* Console input and output
* Decision-making and branching
* Iteration and nested loops
* Functions and modular programming
* Arrays and string manipulation
* Pointers and memory addressing
* Structures and user-defined data types
* Recursion
* Fundamental algorithms
* Programming exercises and problem solving

## 💡 Approach to Problem Solving

An important part of this course is learning to approach programming problems systematically.

My general workflow is:

**Understand the problem → Analyse the requirements → Design the logic → Implement the solution → Test the program → Debug and improve**

This approach helps turn a programming problem into a sequence of smaller and more manageable tasks.

## 🎯 Learning Goals

Through this coursework, I aim to strengthen my understanding of programming fundamentals and develop skills that will be useful for more advanced areas of computer science.

Key areas of development include:

* Logical reasoning
* Algorithmic thinking
* Problem decomposition
* Writing clean and maintainable code
* Debugging and testing
* Understanding memory and program execution
* Independent problem solving

## 🗂️ Repository Structure

The repository will be organised as the course progresses, with programs and assignments grouped according to their respective topics or activities.

This makes it easier to review previous work, track progress, and revisit concepts when needed.
